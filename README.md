# Hito Bench

### これは何？

人間が官能評価（＝好み）で判定するLLMのベンチマークです。
問題やお題を出して日本語の表現力と自然さを評価します。

### なぜ？

LLMは総合的な性能は進化する一方日本語であったり文章力であったりは頻繁に劣化します。また特にオープンウェイトモデルでは海外で人気でも日本語力が非常に残念だったりします

コーディングやら数学やら論理的思考やらは散々他のベンチマークでやられているので、ここではなるべく測らないようにしています

### なぜ人間が判定するの

LLMには自身の表現の不自然さに気付けないという問題があり、人間が判定するしかねえなと

### 評価ぶれない？

ぶれる。いちおう二重盲検でどのモデルかは表示せずに評価できるようにしています。

またこのレポジトリにある評価結果は私のものなので、あなたもやってみるとあなた好みのモデルが見つかると思います。評価が大変になりすぎないようにテスト項目はできる限りしぼっています


ここまで人間が手書き
---
以下、LLMが生成した文章

## セットアップ

[Bun](https://bun.sh/) を使います。

```bash
bun install
```

## 回答を生成する


```bash
bun run generate
```

## 人間が採点する

```bash
bun run serve
```

ブラウザで <http://127.0.0.1:3000> を開きます。同じ問題への回答をまとめ、その中だけをランダムな順番で1件ずつ表示します。画面と API のどちらにもモデル名や runner 名は出しません。

点数は100点を目安にした自由な数値です。小数や100点を超える値も保存できます。コメントは任意の複数行入力です。生成結果は `results/<モデル名-agent名>/<問題ID>.yaml` に保存され、採点すると同じファイルの回答本文より上に点数とコメントが追記されます。集計・結果表示画面はまだありません。
