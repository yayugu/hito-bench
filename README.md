# AIが出力する日本語の自然さを比較 HitoBench

### これは何？

人間が官能評価（＝好み）で判定するLLMのベンチマークです。
問題やお題を出して日本語の表現力と自然さを評価します。

### なぜ？

LLMは総合的な性能は進化する一方日本語であったり文章力であったりは頻繁に劣化します。また特にオープンウェイトモデルでは海外で人気でも日本語力が非常に残念だったりします

コーディングやら数学やら論理的思考やらは散々他のベンチマークでやられているので、ここではなるべく測らないようにしています

### なぜ人間が判定するの

LLMには自身の表現の不自然さに気付けないという問題があり、人間が判定するしかねえなと

### 評価ぶれない？

ぶれる。いちおうモデル名を非表示にしてシャッフルさせて評価しています。

またこのレポジトリにある評価結果は私のものなので、あなたもやってみるとあなた好みのモデルが見つかると思います。評価が大変になりすぎないようにテスト項目はできる限りしぼっています。ここに掲載している数でやると大変なので5モデルくらいで十分です。

### モデルの選定基準
- 人気のもの
- OpenRouterのWeeklyで良く利用されているもの
- 複数バージョンある場合は最新を優先した
- ローカル向けが26B以上となっているのは、これ以下はOpenRouterに置いていないため

## セットアップ

[Bun](https://bun.sh/) を使います。

```bash
bun install
```

## 回答を生成する


```bash
bun run generate
```

## 人間が採点する

```bash
bun run serve
```

ブラウザで <http://127.0.0.1:3000> を開きます。同じ問題への回答をまとめ、その中だけをランダムな順番で1件ずつ表示します。画面にモデル名は出しません。
